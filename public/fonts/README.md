# DONS local fonts

The production fonts are loaded by `next/font/local` from their existing source
folders under `components`:

- `components/Supreme Variable (Indian Type Foundry)/Supreme-Variable.ttf`
- `components/Supreme Variable (Indian Type Foundry)/Supreme-VariableItalic.ttf`
- `components/KULAG SHA/KULAG SHA.otf`

No runtime font requests are made to external services.
